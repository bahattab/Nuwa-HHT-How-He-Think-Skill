# مهارة نُوا (Nuwa)

[English](README.md) · [中文](README_ZH.md) · [日本語](README_JA.md) · [한국어](README_KO.md) · [Español](README_ES.md)

تستخلصُ نُوا طريقةَ تفكير الشخصيّات العامّة من أعمالها وتصريحاتها الموثّقة، وتحوّلها إلى مهارات يمكن لوكيل الذكاء الاصطناعي استخدامها. تشملُ المهارةُ النماذجَ الذهنيّة، وقواعدَ اتّخاذ القرار، وأساليبَ التعبير، وحدودَ الاستنتاج. يدعم المشروعُ معيارَ [Agent Skills](https://agentskills.io)، ويُستخدم مع بيئات مثل Codex وClaude Code وCursor وOpenClaw وHermes Agent وDeepSeek Harness.

## التثبيت

ثبِّت هذه النُّسخة من المستودع باستخدام [أداة التثبيت](https://github.com/vercel-labs/skills):

```bash
npx skills add bahattab/nuwa-skill
```

لتحديد بيئة بعينها، أضِف مثلًا `-a codex` أو `-a claude-code` أو `-a cursor`. ويمكنك أيضًا نسخ مجلّد المهارة إلى مجلّد `skills/` في بيئتك، مع الإبقاء على `SKILL.md` ومجلّد `references/` معًا.

لاستخدامها مع [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)، أضِف الإضافة إلى ملفّ التعريف المطلوب. يستخدم المثالُ الآتي ملفَّ التعريف `web`:

```bash
dsh plugin --profile web add github:bahattab/nuwa-skill
```

أعِد تشغيل DeepSeek Harness بعد التثبيت. لإزالة الإضافة، استخدم `dsh plugin --profile web remove huashu-nuwa`.

## الاستخدام بالعربيّة

بعد التثبيت، اطلب من الوكيل مثلًا:

- «يا نُوا، استخلص طريقة تفكير بول غراهام وأنشئ مهارةً بالعربيّة».
- «أنشئ مهارةً بمنظور تشارلي مونغر، ووثِّق كلَّ نموذج ذهنيّ بمصادره».
- «أحتاج إلى مستشارٍ للتفكير يساعدني على تقييم قراراتي. اقترح عليَّ منهجًا مناسبًا».

وللاستفادة من مهارةٍ أُنشئت بالفعل، يمكنك أن تطلب «حلِّل هذا القرار من منظور مونغر» أو «كيف سيشرح فاينمان الحوسبة الكمّيّة؟».

## آليّة العمل

1. **تسجيل المعرفة السّابقة.** يدوّن الوكيل ما يعرفه قبل البحث، ثم يبحث عمّا يصحّح هذه المعرفة أو يعمّقها أو يضيف إليها.
2. **جمع الأدلّة وحجز عيّنةٍ للتقييم.** يجمع الوكيل الأعمالَ والمقابلات والقرارات الموثّقة، ويحتفظ ببعض الحالات لاختبار المهارة بعد إعدادها.
3. **استخلاص الأنماط.** يحدّد أساليبَ التعامل مع المشكلات والنماذجَ الذهنيّة وقواعدَ القرار وطريقةَ التعبير، ويربط كلَّ نمط بالحالات والمصادر التي تدعمه.
4. **بناء المهارة.** يكتب تعليمات التشغيل في `SKILL.md`، ويضع الحالاتَ والاقتباساتِ في ملفاتٍ مرجعيّةٍ منفصلة.
5. **التقييم.** يقارن أداءَ الوكيل مع المهارة وبدونها، ويستخدم الحالاتَ المحجوزة لاختبار الاستنتاجات، ثم يوثّق النتائجَ في `FIDELITY.md`.

للتفاصيل، راجع [دليل البحث](references/research-playbook.md) و[إطار الاستخلاص](references/extraction-framework.md) و[دليل التحقُّق](references/validation-playbook.md) و[بطاقة تقييم دقّة التمثيل](references/fidelity-scorecard.md).

## حدود المهارة

تصفُ المهارةُ الأنماطَ التي تدعمها الأدلّةُ العلنيّة المتاحة حتّى تاريخ البحث. فرِّق بين الاقتباس الموثَّق والاستنتاج المبنيّ عليه، واذكر الحالاتِ التي لا تكفي فيها الأدلّة لتوقّع موقف الشخص. يمكن إبقاء الاقتباس بلغته الأصليّة وإرفاق ترجمةٍ عربيّةٍ مُبيَّنةٍ بوضوح.

## الأمثلة والمساهمة

تجد في [مجلّد الأمثلة](examples/) مهاراتٍ جاهزةً وملفّاتٍ بحثيّةً لشخصيّاتٍ منها ستيف جوبز وتشارلي مونغر وريتشارد فاينمان. وتضمُّ [الوثائق الإنجليزية](README.md#distilled-people) قائمةَ الشخصيّات والروابط إلى مهاراتها المستقلّة. للاطّلاع على كيفيّة المساهمة، راجع [دليل المساهمة](CONTRIBUTING.md) و[فهرس المجتمع](COMMUNITY.md).
